LifeLink — Blood Donor Connect System

LifeLink is a web application designed to help people find registered blood donors by blood group and city.

Features

- Home page with information about blood donation
- Donor registration
- MySQL database integration
- Search donors by blood group
- Search donors by city
- View donor contact information
- Responsive website design

Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

Requirements

- XAMPP
- PHP
- MySQL
- A web browser

Local Installation

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the "htdocs" directory.
4. Create a MySQL database named "lifelink_db".
5. Import the project's SQL file to create the required tables.
6. Configure the database connection in "config/database.php".
7. Open "http://localhost/lifelink_mysql/" in your browser.

Project Purpose

This project demonstrates how PHP and MySQL can be used to build a basic blood donor directory.

Note: Donor records do not guarantee current availability or medical eligibility. Blood donation must be coordinated with an appropriate medical professional or blood bank.
